What I Build · ASRS Software product

daifuku · intralogistics

At Daifuku, I work on the software layer that makes automated warehouses run — connecting business logic, inventory systems, and physical material-handling equipment.

ASRS (Automated Storage & Retrieval System) is a warehouse automation technology that automatically stores and retrieves loads from high-density rack locations using stacker cranes, conveyors, STVs, and related equipment — coordinated by software.

A modern ASRS typically combines:

  • Storage racks — high-bay structures for dense inventory storage
  • Stacker cranes / shuttles — machines that put away and pick loads
  • Conveyors & STV — transport and sorting between zones
  • WMS software — inventory, orders, and warehouse operations logic
  • WCS software — real-time control of automated equipment
